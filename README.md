# Kyte

A terminal text editor. Always insert like Nano; Esc opens a one-key operator layer; Esc Esc opens a command palette; unsaved work survives a crash.

All rights reserved, license TBD.

## Build and run

```
cargo build --release
target/release/kyte FILE
cargo test
```

`make build | test | lint | e2e | demo | docker-test` wrap the same commands.
