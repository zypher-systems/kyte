Kyte can now update itself, and a buffer you haven't saved yet works like any other file.

## Install

```
curl -fsSL https://raw.githubusercontent.com/zypher-systems/kyte/main/install.sh | sh
```

Or download a `.deb`, `.rpm` or `.tar.gz` below. Each works on x86-64 or arm64 Linux. The installer checks every download against signed checksums.

**Coming from 0.6.0?** It has no updater, so install this release with the script above, or with the package you used before. After that, `kyte --update` does it.

## New

- **Updates.** `kyte --update` installs the newest release the way this copy was installed: with the release's installer, the release's package, the repository the package came from, or your AUR helper. It tells you what it will do and asks first. A build from source, or a copy it can't place, is refused with what to do instead. `--update-check` only says whether one is out, `--update-to` installs a chosen version, and `--update-rollback` goes back.
- **Signed updates.** Nothing from a release is used until its checksums match the release key built into Kyte, and the download matches its checksum.
- **Check for updates.** At most once a day, Kyte asks GitHub in the background and says on the status bar if a release is out. It never installs anything by itself. The palette's **Check for updates** asks now.
- **History before the first save.** An unsaved buffer keeps file history from the first keystroke, and the first save moves it to the file, so Esc `h` goes back to the empty buffer.
- **Highlighting before the first save.** With no file name, Kyte works out the language from the first few lines. It's cautious, so plain writing stays plain.
- **Set language.** This palette command picks a file's language, including a file Kyte can't identify by name. **Automatic** goes back to detecting it, and **Plain text** turns a wrong guess off.

## Changed

- **Kyte now uses the network.** It used to make no connections at all. Now it connects to GitHub for updates and nothing else, which shows GitHub your address and Kyte's version. `update_check = false` turns off the daily check, and a build with `--no-default-features` has no network code.
- Discarding an unsaved buffer deletes its history too.
- The binary is about 38 MB. A build with `--no-default-features` is still about 1.3 MB.

## Fixed

- Building an unnamed LaTeX buffer asks for a name instead of doing nothing.
- Open PDF no longer says an unnamed LaTeX buffer isn't LaTeX.
