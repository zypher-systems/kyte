Kyte's first public release. It adds what an everyday editor needs, and enough to write a research paper in.

## Install

```
curl -fsSL https://raw.githubusercontent.com/zypher-systems/kyte/main/install.sh | sh
```

Or download a `.deb`, `.rpm` or `.tar.gz` below. Each works on x86-64 or arm64 Linux. The installer checks every download against signed checksums.

## New

- **Several open files.** Ctrl-O adds a file and leaves the others open. Esc `b` lists them, Esc `.` and Esc `,` move between them, and Ctrl-W closes one. You can also start with `kyte a.txt b.txt`.
- **File tree.** Ctrl-T opens a box, unfolded to the file you're in.
- **Six themes.** Signal, Harbor, Dusk, Ember, Moss and Daybreak. **Choose theme** in the palette shows each one as you move through the list, and `theme` in the settings file keeps your choice.
- **33 languages.** Highlighting now covers SQL, Java, C#, PHP, Ruby, Lua, Swift, Zig, Nix, Fish, XML, INI, Makefiles, Dockerfiles, CMake, diffs, LaTeX and BibTeX, along with the 15 from before. Function keys work in the new languages that have functions.
- **Writing.** Markdown, text and LaTeX files wrap, show a word count, and underline misspelled words. Esc `m` moves to the next one, and Esc `z` offers suggestions. `writing = false` turns this off.
- **Research papers.** Finishing `\cite{` offers the works in your bibliography. Ctrl-B builds the PDF beside the editor, and a failed build lists its errors so Enter can take you to the line. This needs LaTeX installed, with `latexmk` by default.
- **A new look.** Every menu is a centred floating box, and the status bar and cursor line are redrawn.
- **Line numbers.** Esc `l` turns them on or off for one file.

## Changed

- Ctrl-O no longer replaces the current file, so it no longer asks about unsaved changes. Quitting asks about each unsaved file instead.
- Opening the file you're already in says `Already open` rather than reloading it. To go back to the saved version, close it with Ctrl-W, answer `n`, and open it again.
- Colors use 24-bit color when `COLORTERM` says the terminal can, and a close 256-color match otherwise.
- The binary is about 34 MB, because of the new grammars. A build with `--no-default-features` is about 1.3 MB.

## Fixed

- Keeping your side of a review now marks the file as unsaved, and a crash right afterwards no longer loses it.
- Save As no longer overwrites the edits a crashed session left for that file.
