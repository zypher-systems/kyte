Kyte 0.7.1 fixes four bugs. One of them could lose unsaved work, so it's worth updating.

## Install

```
curl -fsSL https://raw.githubusercontent.com/zypher-systems/kyte/main/install.sh | sh
```

Or download a `.deb`, `.rpm` or `.tar.gz` below. Each works on x86-64 or arm64 Linux. The installer checks every download against signed checksums.

**Coming from 0.7.0?** Run `kyte --update`.

## Fixed

- **Saving through a symlink that moved.** If a symlink you had open was pointed at a different file, saving could wipe that file's crash recovery, or overwrite it while another Kyte had it open. Kyte now refuses the save and says why, as Save as always has.
- **Replacing an accent.** Replace changed the wrong character when the match was a combining mark: with `e` followed by a combining accent, it changed the `e`. Skipping such a match with `n` also never moved on.
- **Replace after it wraps round.** Past the end of the file, Replace could offer a match that ran beyond where it started. Removing one crashed debug builds and lost track of the stopping point in release builds. Replace now stops short of such a match.
- **Replace all the rest.** `a` now takes the same matches as answering `y` to each one. It could skip the match on screen.
- **Very long file names.** A file whose name was close to the 255-byte limit opened but couldn't be saved.
